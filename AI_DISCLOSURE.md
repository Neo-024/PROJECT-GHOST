# AI and tool disclosure

This project was prepared with AI assistance for initial code generation, interface structure, and draft explanatory text. The participating team must review, test, correct, and take responsibility for all submitted material.

No AI-generated NASA logo, flag, mission identifier, or other NASA branding should be used. If AI-generated images or videos are added, place a visible watermark on those assets indicating that they are AI-generated. List the actual AI tools and the actual ways they were used in the official project submission.

Do not claim that an AI historian uses NASA sources live unless a retrieval system and citations have actually been implemented. The included Archive Guide is a local rule-based prototype using the bundled data records.
